## Run a practical
Install Python 3, then run a file from the repository folder, e.g. `python exp01_bubble_sort.py`.

## Notes
- These are short revision versions; understand the logic and adjust input/output to match your instructor's expectations.
- Experiment 12 currently uses exhaustive tour enumeration as a compact TSP example, not the manual's full least-cost Branch-and-Bound matrix-reduction algorithm. That exact variant should be implemented if your examiner expects it.
- Huffman codes and Vertex Cover results can vary due to tie-breaking or edge order.
